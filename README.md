## ⚡ About The Project

**"I don't just write code; I secure it."**

This portfolio was engineered to bridge the gap between **Offensive Security** and **High-Performance Web Development**. Unlike standard portfolios, this project treats the user experience as a "Command Center," utilizing a dark, cyber-aesthetic interface with zero-compromise performance.

It serves as a central hub to showcase:
* **Security Research** (CVEs, Pen-testing reports)
* **Full Stack Applications** (Rust, React, Python)
* **Certifications** (CEH, Security+, AWS)

## 🌟 Key Features

### 🎨 Visual & UI
* **Cinematic "Stagger" Animations:** Elements enter the screen sequentially using Framer Motion.
* **Blur-Reveal Typography:** Text un-blurs into existence for a high-end feel.
* **Glassmorphism Dashboard:** A responsive Bento Grid layout with frosted glass effects (`backdrop-blur`).
* **Reactive Hover States:** Cards lift and glow upon interaction, mimicking premium native apps.

### ⚙️ Technical
* **Zero-JS Core:** Built on [Astro](https://astro.build), serving HTML by default for 100/100 Lighthouse scores.
* **Island Architecture:** React components (`client:load`) are only hydrated where interactivity is needed.
* **Typewriter Effect:** Custom hook implementation for dynamic role switching.
* **Responsive Design:** Mobile-first approach ensuring perfect rendering on iPhone, iPad, and 4K Displays.
